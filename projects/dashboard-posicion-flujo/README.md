# Dashboard de posición y flujo bancario

## Objetivo

Centralizar en una sola vista la posición bancaria y los flujos de efectivo para facilitar el seguimiento de liquidez.

## Indicadores demostrativos

- Saldo inicial.
- Entradas.
- Salidas.
- Flujo neto.
- Saldo final.
- Comparación por banco y fecha.
- Brecha de liquidez por horizonte.
- Concentración de pasivos por fondeador.
- Composición de cartera.

## Tecnologías

- Python y pandas para transformación.
- Streamlit para la interfaz.
- Plotly para visualizaciones interactivas.
- CSV sintético como fuente de datos.

## Privacidad

La aplicación usa instituciones ficticias identificadas como Banco Demo 01, Banco Demo 02, etc. No contiene números de cuenta, CLABE, beneficiarios ni saldos reales.
